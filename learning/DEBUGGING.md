# 🐛 Debugging Track

Debugging is evidence-led investigation.

```text
REPRODUCE
-> OBSERVE
-> HYPOTHESISE
-> ISOLATE
-> SMALLEST RELIABLE FIX
-> RERUN
-> VERIFY
```

Connor should progressively distinguish syntax, runtime, logic, state, input, rendering and environment failures.

Do not rewrite the whole program when a small fix can isolate the cause. A changed error is evidence, not automatically success. Always rerun the original reproduction after the fix.
