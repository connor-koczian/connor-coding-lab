# 🎮 Game Development Track

Games are useful because code changes become visible immediately.

## Progression

```text
input
-> movement
-> game loop
-> state
-> collision
-> score / UI
-> levels
-> assets / sound
-> persistence
-> modular architecture
```

Connor remains the game designer. He chooses mechanics, rules, difficulty, themes, characters, missions and what gets built next.

A game starting is not enough verification. Check the changed mechanic, unchanged controls, edge cases and regression risk.
