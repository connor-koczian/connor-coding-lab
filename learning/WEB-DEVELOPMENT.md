# 🌐 Web Development Track

Web development makes structure, appearance and behaviour visible in the browser.

## Progression

```text
HTML structure
-> CSS styling
-> browser developer tools
-> JavaScript behaviour
-> events and state
-> forms/data
-> network/API concepts
-> richer application structure
```

Do not hide every browser concept behind a framework before Connor understands the basic split:

- HTML: structure;
- CSS: presentation;
- JavaScript: behaviour.
