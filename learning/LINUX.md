# 🖥️ Linux & Terminal Track

The terminal is a direct way to inspect and control the development environment.

The goal is not memorising commands. It is understanding location, files, processes and authority.

## Core progression

```text
pwd / ls / cd
-> paths and files
-> command arguments
-> running project commands
-> processes
-> permissions
-> environment variables
-> networking basics
-> safe maintenance boundaries
```

Connor should know that the current directory matters, relative and absolute paths differ, command success does not prove an application is correct, and normal coding should not routinely need `sudo`.
