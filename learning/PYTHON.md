# 🐍 Python Track

Python is used to build a correct mental model of programs, not to measure typing endurance.

## Core progression

```text
input/output
-> variables and values
-> conditions
-> loops
-> functions
-> lists and dictionaries
-> modules
-> files and data
-> tests
-> larger program structure
```

Objects/classes are introduced when they solve a real project problem rather than because they appear on a checklist.

Connor should increasingly be able to predict behaviour, explain values and control flow, direct bounded changes, use the declared `uv` workflow and verify results with runtime evidence or tests.

## Tooling rule

Use the repository's declared project workflow. For the current Python projects this means `uv`, not raw `pip`.
