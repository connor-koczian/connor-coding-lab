# 🌿 Git & GitHub Track

Git is the evidence trail and save-point system for code.

## Core progression

```text
status
-> diff
-> stage one intended file
-> diff --cached
-> commit
-> log
-> branch
-> merge
-> remotes
-> pull / push
-> pull request
-> review
```

Do not teach `git add .` as the default. Connor should inspect the change and stage the specific file or files that belong in the save point.

Before a commit Connor should increasingly answer what changed, why, what evidence says it works, which files belong and what the commit message should explain.
