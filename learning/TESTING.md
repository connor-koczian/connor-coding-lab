# 🧪 Testing & Verification Track

Testing answers:

> What evidence would make us believe this behaviour is correct?

## Core progression

```text
run and observe
-> expected versus actual
-> automated test
-> useful assertion
-> failure case
-> regression test
-> test boundaries
-> CI
```

A passing test proves only what that test checks.

Connor should learn to identify the input, action, expected result and important behaviour not covered. Runtime checks, automated tests and interactive GUI checks are different evidence types.
