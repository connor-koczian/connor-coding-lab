# 🏗️ Software Engineering Track

Software engineering connects individual coding skills into reliable project work.

## Progression

```text
goal
-> requirements
-> constraints
-> acceptance checks
-> files/components
-> small coherent change
-> review
-> dependencies
-> interfaces/APIs
-> architecture
-> CI and release thinking
```

Before meaningful implementation Connor should increasingly establish the goal, relevant files/components, important concept, constraints and success checks.

Afterwards inspect what changed, run relevant checks, distinguish verified from unverified behaviour and review the Git save point.
