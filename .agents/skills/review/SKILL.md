# /review

1. inspect status and diff;
2. explain the change;
3. identify problems and risks;
4. check what validation exists;
5. check for secrets and unintended files;
6. distinguish required fixes from optional improvements;
7. confirm Connor understands the important parts;
8. only then stage specific files or recommend a save point.
