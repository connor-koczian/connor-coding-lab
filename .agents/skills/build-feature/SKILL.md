# Build Feature

Before editing:

1. inspect branch/status and relevant files;
2. confirm the bounded goal;
3. identify files;
4. explain the important concept;
5. state the validation plan.

During implementation:

- make the smallest coherent change;
- preserve unrelated behaviour;
- avoid unnecessary dependencies;
- keep code readable.

After implementation:

1. run applicable static/automated/runtime checks;
2. report what was and was not verified;
3. inspect the diff;
4. explain the important change;
5. preserve a meaningful Connor decision;
6. do not commit a large unexplained change.
