# /debug

Use:

`reproduce -> observe -> hypothesise -> isolate -> smallest reliable fix -> rerun -> verify`

Keep Connor involved in interpreting evidence.

State the likely root cause before proposing broad changes.

Do not replace the whole program because one part is broken.
