name: plan-feature
description: Produces a bounded implementation plan for a feature after inspecting the current code and constraints. Use before substantive feature work or when the change spans multiple files.
---

# Plan Feature

1. Inspect current repository state and relevant files.
2. Restate the goal and constraints.
3. Identify files likely to change.
4. Explain the key concept or architecture.
5. Separate required work from optional ideas.
6. Define validation and acceptance checks.
7. Identify risks or unknowns.
8. Prefer the smallest coherent change.
9. Do not edit files unless the user has asked to proceed with implementation.
