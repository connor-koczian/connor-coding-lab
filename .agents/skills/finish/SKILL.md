# /finish

1. Summarise what was attempted and what changed.
2. Run or inspect applicable checks.
3. State what remains unverified.
4. Review Git status and diff.
5. Confirm the important change is understandable.
6. If a clean bounded save point is ready, use the normal reviewed commit flow.
7. Identify what Connor personally demonstrated: explanation, execution, decision/specification, debugging or verification.
8. Apply the `update-master-tracker` skill only to evidence materially produced by the session.
9. Do not promote a capability merely because Antigravity implemented something or validation passed.
10. If no learner evidence was produced, leave capability state unchanged.
11. Record or state one useful next mission.
