# Start Session

1. Read root `GEMINI.md` and the current V2 master implementation plan if repository governance matters.
2. Inspect current Git branch/status before proposing changes.
3. If `progress/CONNOR-MASTER-TRACKER.md` exists, read it. If it does not exist, state that Phase 3 has not established canonical learner state and do not invent it.
4. Identify active/unfinished work from source-supported repository evidence.
5. Summarise where Connor is, what he is learning, the next bounded action, how to run it and how success will be checked.
6. Prefer one useful next mission, with one optional harder stretch.
7. Do not modify files merely to start a session.
