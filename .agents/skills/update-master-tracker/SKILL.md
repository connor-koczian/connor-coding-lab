# Update Master Tracker

Canonical file: `progress/CONNOR-MASTER-TRACKER.md`.

## Gate

If the file does not exist, stop. State that Phase 3 has not created the canonical tracker. Do not create an alternative tracker and do not invent learner state.

## Evidence rules

- Record what happened factually.
- Distinguish AI implementation from Connor-demonstrated capability.
- Do not upgrade a skill because the code works.
- Use evidence from Connor's explanation, decisions, debugging, verification or independent execution.
- Keep `CAN DIRECT AI` distinct from `CAN VERIFY AI`.
- Preserve uncertainty where evidence is weak.

Update only the sections materially affected by the session.
