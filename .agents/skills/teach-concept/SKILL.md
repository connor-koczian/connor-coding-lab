# Teach Concept

1. Name the real technical concept.
2. Explain why it matters in the current task.
3. Point to the smallest relevant code or system example.
4. Explain the mental model before syntax details.
5. Ask Connor to predict, explain or change one meaningful thing.
6. Correct misunderstandings with evidence.
7. Offer one short practice challenge only if it helps.
8. Do not treat a correct AI-generated answer as evidence Connor understands the concept.
