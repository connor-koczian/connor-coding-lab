# 🐍 Mission PY-01 — Predict, Change, Explain

**Track:** Python

## Where am I?

The independent **Python Basics** project repository.

## What am I learning?

Values, input/output and predicting behaviour before execution.

## What do I do next?

1. Read the current small Python entry point with Antigravity.
2. Connor predicts what it will ask and print.
3. Run the program using the repository's declared `uv` workflow.
4. Choose one small visible behaviour change.
5. Either Connor edits it or gives Antigravity a bounded change request.
6. Run it again.
7. Run the applicable tests.
8. Explain which line/value caused the visible change.

## How do I run it?

Antigravity must verify the current entry point and commands from the **Python Basics workspace root** and its `pyproject.toml` before running them.

## How do I know it worked?

The new behaviour is visible, applicable tests pass, and Connor can connect the result to the important code/value.

## Connor decides

Connor chooses the exact wording or behaviour to change.
