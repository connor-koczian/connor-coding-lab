# 🏗️ Mission ENG-01 — Plan Before Building

**Track:** Software engineering

## Where am I?

Any current small project or practice task with a meaningful change to make.

## What am I learning?

Turning a feature idea into a small coherent implementation plan.

## What do I do next?

1. State the goal in one sentence.
2. Ask Antigravity to inspect the repository and identify the relevant files.
3. Connor confirms or challenges the scope.
4. State the important concept or component.
5. Write 2–4 acceptance checks.
6. Identify one risk or likely regression.
7. Only then decide whether to implement.
8. After implementation, compare the actual diff with the plan.

## How do I run it?

The plan must be based on inspected current files, not guessed paths.

## How do I know it worked?

The implementation, if performed, stays within the agreed scope or deviations are explicitly explained.

## Connor decides

Connor decides whether the plan is small enough and which acceptance check matters most.

## Tracker evidence

Do **not** promote capability merely because Antigravity completed the work.

Potential evidence from this mission:

- DECISION / SPECIFICATION: scope and acceptance criteria.
- EXPLANATION: important component.
- VERIFICATION: compares plan, diff and evidence.

## Harder challenge

Offer two implementation options with trade-offs and have Connor choose before code changes begin.
