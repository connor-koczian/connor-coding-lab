# 🧭 Mission FND-01 — First Evidence Cycle

**Track:** Foundations / cross-track

## Where am I?

Mission Control, using the current workspace and one existing small project.

## What am I learning?

How location, execution, verification and Git evidence fit together before a save point.

## What do I do next?

1. Use `pwd` and `git status` and explain what each tells you.
2. Choose **Python Basics** or another current project whose run command Antigravity verifies from repository files.
3. Predict one thing that should happen when it runs.
4. Run it.
5. Run its applicable test/check if one exists.
6. Inspect `git status` again.
7. Explain what evidence you now have and what is still unverified.

## How do I run it?

Use the project's **declared current workflow**. Antigravity must inspect the repository first and must not invent a command.

## How do I know it worked?

- Connor knows where the terminal is.
- The chosen program/check actually executes.
- Connor can distinguish program output, test evidence and Git state.
- No learner files need to be changed merely to complete this mission.

## Connor decides

Connor chooses which existing project to investigate.
