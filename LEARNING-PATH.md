# Connor's Learning Path

This is a progression, not a race. Move forward when the previous level makes sense.

## Level 1 — Terminal explorer

Learn:

- `pwd`, `ls`, `cd`
- where projects live
- files versus folders
- how to run a program

Proof: navigate to a project and run it without guessing.

## Level 2 — Python pilot

Learn:

- variables
- strings and numbers
- `input()` and `print()`
- `if` / `else`
- loops
- functions

Home base: `python-basics/`.

Proof: change a small program, predict what it will do, then run it.

## Level 3 — Git save points

Learn:

- `git status`
- `git diff`
- `git add`
- `git commit`
- `git log`

Proof: make one intentional change and create a clear commit without AI doing the Git commands blindly.

## Level 4 — Game mechanics

Use Snake to understand:

- game loops
- input
- position and movement
- collisions
- scoring
- state
- timing

Proof: explain one mechanic and change it safely.

## Level 5 — Branches

Learn:

- why `main` stays stable
- `git switch -c`
- working on one feature at a time
- merging completed work

Proof: build a small Snake feature on a branch.

## Level 6 — Neon City

Start an original top-down open-world game.

Progression:

1. player movement
2. camera/map
3. buildings and roads
4. pickups
5. NPCs
6. missions
7. vehicles
8. inventory/upgrades
9. arena challenge
10. save/load

The point is to learn how larger games are split into systems.

## Level 7 — Testing and debugging

Learn:

- reproduce a bug
- read a traceback
- write a small test
- use `pytest`
- use `ruff`

Proof: find a bug, explain it, test the fix.

## Level 8 — Web game development

Use `web-playground/` to learn:

- HTML
- CSS
- JavaScript
- browser developer tools
- Canvas

Compare the browser Snake with the Python/Pygame version.

## Level 9 — GitHub collaboration

Learn:

- push/pull
- pull requests
- review
- issues
- useful commit messages

Proof: complete one feature entirely through a branch and pull request.

## Level 10 — Build your own project

Connor chooses the project and architecture.

AI can help, but Connor should be able to explain:

- what the program does
- where the important code lives
- how to run it
- how to test it
- how Git records its history
