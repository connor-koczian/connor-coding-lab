# Python Practice

Short drills for one concept at a time.

Try ideas such as:

1. Predict the output of a five-line program before running it.
2. Change one variable and explain the new output.
3. Write or direct one `if` condition.
4. Replace repeated code with a function.
5. Choose between a list and dictionary and explain why.

Use a temporary practice file or the current learning project only when the change is clearly bounded.

The success check is understanding plus observed behaviour, not line count.
