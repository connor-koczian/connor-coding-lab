# Git Practice

Use a disposable or deliberately bounded change.

Practice:

1. `git status`
2. `git diff -- <file>`
3. stage one specific intended file;
4. `git diff --cached`;
5. unstage when appropriate;
6. inspect `git log -1 --oneline`.

The goal is to understand Git state transitions.

Do not use force-push, history rewriting or `git add .` as the normal beginner path.
